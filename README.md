# Pastelería Mil Sabores

Proyecto de tienda online desarrollado con React, Vite y Bootstrap para Desarrollo Fullstack II.

Incluye catálogo, filtros por categoría, registro e inicio de sesión, carrito y pago simulado. La administración permite consultar pedidos y boletas, actualizar stock, revisar reportes e historial de compras.

Los datos se guardan en localStorage. Algunas pantallas quedan solo como diseño para esta etapa.

## Instalación y ejecución

```bash
npm install
npm run dev
```

## Pruebas y cobertura

```bash
npm run test -- --run
npm run test:coverage
```

El reporte de cobertura se genera en `coverage/index.html`.
